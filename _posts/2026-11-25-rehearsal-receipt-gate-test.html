AI-assisted: drafted by AI from the source material, then reviewed and approved by a human editor before publishing. How TFR is made

This is a rehearsal article. It exists only in the preview catalog and publishes only to the preview site.

The point of the exercise is to prove that TFR's publish path honors its two approval gates. A draft needs a signed gate-1 receipt before it can reach gate 2, and gate 2 needs a valid receipt bound to the exact content that was approved. Edit the draft after approval and the receipt stops matching, so the publisher refuses to ship it.

What this run checks

First, the publisher opens a pull request against the preview repository instead of pushing to a live branch. Second, the article body carries the AI-assisted disclosure line at the top. Third, the post lands in the posts index and the sitemap with the correct slug and path.

Why it matters

A fully automated publication has no editor catching mistakes at the last second. The gates, receipts and SEO check are that editor. This test confirms they hold before any real reader sees a post.

If you can read this on the preview site, the pipeline did its job.
